# Contributing

Thanks for helping make Prompt Game better! This is a small, beginner-friendly project, so keep changes simple and readable.

## Quick start

1. Fork the repo and clone your fork.
2. Open `index.html` locally (no build step).
3. Make your change.
4. Test in a browser.
5. Open a pull request with a clear title and description.

## Good first issues

- Add a new level (10 levels, anyone?).
- Improve mobile layout for the sort challenge.
- Add a live-model sandbox via a serverless function.
- Fix typos or awkward translations.

## Guidelines

- Keep it zero-dependency unless there is a strong reason.
- Every user-facing string must exist in both `js/i18n.js` (UI) and `js/levels.js` (level content).
- Keep content original; do not copy the Anthropic tutorial text verbatim.
- Follow the existing level data shape when adding levels.
